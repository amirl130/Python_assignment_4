## 第二部分：方案B——相关系数热力图

### 2.1 代码

以下是热力图的完整代码：

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取数据
df = pd.read_csv('brics_fdi_timeseries.csv')

# 计算相关系数矩阵
numeric_cols = ['GDP_growth', 'FDI_inflow', 'GDP_percapita']
correlation_matrix = df[numeric_cols].corr()

# 绘制热力图
plt.figure(figsize=(8, 6))
sns.heatmap(
    correlation_matrix,
    annot=True,           # 显示数值
    cmap='coolwarm',      # 红蓝色系
    center=0,             # 中心为0
    square=True,          # 正方形格子
    linewidths=1,         # 格子间白线
    cbar_kws={'shrink': 0.8, 'label': 'Correlation'}
)

plt.title('Correlation Matrix\nGDP Growth, FDI Inflow, GDP per Capita', fontsize=14)
plt.tight_layout()
plt.savefig('heatmap_brics.png', dpi=150)
plt.show()

print(correlation_matrix.round(3))
