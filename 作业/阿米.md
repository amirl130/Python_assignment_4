## 第一部分：功能实现（20分）

### 游戏说明

本游戏是一款文字类大学生活模拟器。玩家通过在每个学期选择不同的活动，影响自身的知识值、身体健康值、心理健康值、学分和平均绩点（GPA），最终目标是顺利读完大学四年并毕业。每个选择都会实时改变玩家的状态，并通过后续的健康检查影响游戏进程。

### 胜利条件

- 总学分 ≥ 140
- 四年平均绩点（GPA）≥ 2.1
- 身体健康值 > 25 且 心理健康值 > 40（否则被退学）

### 核心玩法

游戏共4个学年，每学年包含2个学期。每个学期玩家可以从以下5种行动中选择一种：

| 选项 | 行动 | 效果 |
|------|------|------|
| S | 学习 | 知识 ↑，身体 ↓，心理 ↑ |
| P | 娱乐/休息 | 心理 ↑，知识 ↓ |
| E | 运动 | 身体 ↑，心理 ↑，知识 ↓ |
| X | 独自一人 | 心理 ↓ |
| Y | 和朋友一起 | 心理 ↑ |

每学年结束后，会根据当前知识值自动进行期末考试，知识越高，考试成绩越好，GPA越高。四年结束后判断是否满足毕业条件。

### 1.2 设计思路与游戏逻辑（10分）

本游戏以「顺利读完四年大学并毕业」为目标，模拟大学生活中的学习、娱乐、运动、社交等决策，并引入随机性与状态反馈机制。具体设计如下：

#### 1. 模块化设计

| 模块 | 功能 |
|------|------|
| 初始化模块 | 设定知识、身体健康、心理健康、学分、GPA等初始值 |
| 主循环模块 | 按学年（1-4年）和学期（每学年2学期）进行循环 |
| 事件处理模块 | 根据玩家选择（S/P/E/X/Y）更新各项属性 |
| 考试模块 | 每学年末根据知识值决定考试成绩区间，计算绩点 |
| 健康与GPA检查模块 | 实时监测健康和绩点，触发退学或失败结局 |
| 结局判定模块 | 四年结束后判断是否毕业 |

#### 2. 玩家互动

- 使用 `input()` 函数让玩家在每学期选择活动（S/P/E/X/Y）
- 实时反馈选择后的状态变化（知识、身体健康、心理健康数值增减）

#### 3. 运气系统

- 知识、健康、心理的变化值使用 `random.randint()` 在合理区间内随机生成
- 考试成绩与知识值挂钩，但在同一区间内仍随机波动
- 每学年获得的学分也是随机范围（30-45），避免每局结果完全相同

#### 4. 状态更新机制

- 每完成一次选择，立即更新知识、健康、心理并显示
- 每学年末更新总学分、平均绩点并显示
- 健康或心理过低时立即游戏失败
- 大二后平均绩点低于2.1也会失败，模拟大学淘汰机制

## 第一部分：任务理解与边界界定（10分）

### 我的「一种解法」判定标准

在输入数据相同的前提下，若两段代码的**核心机制**不同（**归约顺序、内存模型、调用栈结构**三者有至少一项本质差异），则视为不同解法。仅语法糖不同、仅参数默认值不同，算同一种。

### 边界案例说明

| 案例 | 判定 | 理由 |
|------|------|------|
| `sum(lst)` 与 `sum(lst, 0)` | **同一种** | 两者调用的是同一个内置函数，归约机制完全相同，唯一区别是起始累积值是否显式写出，属于参数变体 |
| `for` 累加 与 `while` 累加 | **不同种** | `for`是定循环（遍历对象确定），`while`是不定循环（循环条件可以更灵活），控制流结构不同 |
| `sum_listcomp` 与 `sum_generator` | **不同种** | 前者显式构建完整列表（O(n)额外内存），后者惰性求值（O(1)额外内存），内存模型本质不同 |

- FDI流入额（BoP, current US$）：BX.KLT.DINV.CD.WD
- 人均GDP（current US$）：NY.GDP.PCAP.CD

### 样本范围

- 国家：巴西、俄罗斯、印度、中国、南非（BRICS五国）
- 时间跨度：2010-2019年（10年）
- 样本量：5个国家 × 10年 = 40条面板数据

---

## 数据描述

### 变量说明

| 变量名 | 中文名称 | 单位 | 说明 |
|--------|---------|------|------|
| country | 国家名称 | - | 巴西、俄罗斯、印度、中国、南非 |
| year | 年份 | 年 | 2010-2019 |
| gdp_growth | GDP增长率 | % | 年度GDP实际增长率 |
| fdi_inflow | FDI流入额 | 现价美元 | 国际收支平衡表中的FDI净流入 |
| gdp_per_capita | 人均GDP | 现价美元 | 人均国内生产总值 |

### 数据结构

- 原始数据：三个独立的CSV文件（每个指标一个文件）
- 处理后的数据：**面板数据（Panel Data）**
  - 维度：国家 × 时间
  - 行数：40行（5国 × 10年）
  - 列数：5列（country, year, gdp_growth, fdi_inflow, gdp_per_capita）

### 数据质量说明

| 项目 | 说明 |
|------|------|
| 缺失值 | 经检查，原始数据中部分年份数据缺失，采用前向填充法处理 |
| 异常值 | 未发现明显异常值 |
| 数据类型 | 数值型变量均为float64，年份为int64，国家为object |

---

## 数据获取与处理

### 1. 数据下载

从世界银行平台分别下载三个指标的CSV文件：

| 文件名 | 内容 |
|--------|------|
| `gdp_growth_brics.csv` | BRICS国家GDP增长率（2010-2019） |
| `fdi_inflow_brics.csv` | BRICS国家FDI流入额（2010-2019） |
| `gdp_per_capita_brics.csv` | BRICS国家人均GDP（2010-2019） |

### 2. 数据合并与清洗代码

```python
import pandas as pd

# 1. 读取三个CSV文件
gdp_growth = pd.read_csv('gdp_growth_brics.csv')
fdi_inflow = pd.read_csv('fdi_inflow_brics.csv')
gdp_per_capita = pd.read_csv('gdp_per_capita_brics.csv')

# 2. 查看数据结构
print("GDP增长率数据形状：", gdp_growth.shape)
print("FDI数据形状：", fdi_inflow.shape)
print("人均GDP数据形状：", gdp_per_capita.shape)

# 3. 将横截面数据转换为面板数据
def melt_brics_data(df, value_name):
    """将世界银行格式的宽表转换为长表面板数据"""
    df_melted = df.melt(
        id_vars=['Country Name', 'Country Code', 'Indicator Name', 'Indicator Code'],
        var_name='year',
        value_name=value_name
    )
    # 只保留2010-2019年
    df_melted = df_melted[df_melted['year'].astype(int).between(2010, 2019)]
    # 重命名国家列
    df_melted = df_melted.rename(columns={'Country Name': 'country'})
    return df_melted[['country', 'year', value_name]]

# 4. 分别转换三个数据集
gdp_growth_clean = melt_brics_data(gdp_growth, 'gdp_growth')
fdi_inflow_clean = melt_brics_data(fdi_inflow, 'fdi_inflow')
gdp_per_capita_clean = melt_brics_data(gdp_per_capita, 'gdp_per_capita')

# 5. 合并三个数据集
merged_data = gdp_growth_clean.merge(fdi_inflow_clean, on=['country', 'year'])
merged_data = merged_data.merge(gdp_per_capita_clean, on=['country', 'year'])

# 6. 数据类型转换
merged_data['year'] = merged_data['year'].astype(int)
merged_data['gdp_growth'] = pd.to_numeric(merged_data['gdp_growth'], errors='coerce')
merged_data['fdi_inflow'] = pd.to_numeric(merged_data['fdi_inflow'], errors='coerce')
merged_data['gdp_per_capita'] = pd.to_numeric(merged_data['gdp_per_capita'], errors='coerce')

# 7. 处理缺失值（前向填充）
merged_data = merged_data.sort_values(['country', 'year'])
merged_data = merged_data.groupby('country').fillna(method='ffill')

# 8. 删除仍然存在的缺失值
merged_data = merged_data.dropna()

# 9. 重置索引
merged_data = merged_data.reset_index(drop=True)

# 10. 确认面板数据结构
print("最终面板数据形状：", merged_data.shape)
print("国家列表：", merged_data['country'].unique())
print("年份范围：", merged_data['year'].min(), "-", merged_data['year'].max())

# 11. 保存最终数据
merged_data.to_csv('brics_fdi_timeseries.csv', index=False)
print("数据已保存为 brics_fdi_timeseries.csv")
