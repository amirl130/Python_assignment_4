### 三、五项元数据示例

以 `sum_kahan` 为例，每种解法都包含以下五项：

#### 名称：sum_kahan（Kahan 补偿求和算法）

**原理：**
每步维护误差补偿量 c，用 y = x - c 修正当前元素，t = s + y 后计算新误差 c = (t-s)-y，显著降低浮点累积误差。

**适用场景：**
受限环境下无法用 math.fsum 但需要自行实现高精度求和；嵌入式或纯 Python 环境。

**已知坑：**
- 比普通 sum 慢约 4 倍
- 代码逻辑不直观，不熟悉的人难以维护
- 极端对消场景仍有残余误差

**AI标注：** AI生成我读懂了
