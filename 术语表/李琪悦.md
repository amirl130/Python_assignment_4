## 一、数据类型

| 术语 | 说明 | 示例 |
|------|------|------|
| int | 整数类型 | `x = 5` |
| float | 浮点数类型 | `x = 3.14` |
| str | 字符串类型 | `name = 'Li'` |
| bool | 布尔类型 | `flag = True` |
| list | 列表，可变有序序列 | `[1, 2, 3]` |
| tuple | 元组，不可变有序序列 | `(1, 2, 3)` |
| dict | 字典，键值对存储 | `{'name': 'Li', 'age': 20}` |
| None | 空值对象 | `x = None` |

| 术语 | 说明 | 示例 |
