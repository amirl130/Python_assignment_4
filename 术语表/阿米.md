# Python 重要术语表

## 一、基础语法

| 术语 | 英文 | 解释 |
|------|------|------|
| 变量 | Variable | 存储数据的容器，如 `x = 5` |
| 数据类型 | Data Type | 数据的种类，如整数、浮点数、字符串 |
| 关键字 | Keyword | Python保留字，不能用作变量名，如 `if`、`for`、`while` |
| 注释 | Comment | 解释代码的文字，用 `#` 开头 |
| 缩进 | Indentation | Python中用空格或制表符表示代码块 |
| 语句 | Statement | 一行代码，如 `print("hello")` |
| 表达式 | Expression | 能计算出值的代码，如 `1 + 2` |

## 二、数据结构

| 术语 | 英文 | 解释 |
|------|------|------|
| 列表 | List | 有序、可变、可重复的集合，用 `[]` |
| 元组 | Tuple | 有序、不可变、可重复的集合，用 `()` |
| 字典 | Dictionary | 键值对集合，无序、可变，用 `{}` |
| 集合 | Set | 无序、可变、元素唯一，用 `{}` 或 `set()` |
| 字符串 | String | 字符序列，不可变，用 `''` 或 `""` |
| 切片 | Slice | 获取序列的子集，如 `[1:5]` |

## 三、流程控制

| 术语 | 英文 | 解释 |
|------|------|------|
| 条件判断 | Conditional | `if-elif-else` 结构 |
| 循环 | Loop | 重复执行代码块，如 `for`、`while` |
| 遍历 | Iteration | 逐个访问集合中的元素 |
|  break | break | 跳出当前循环 |
| continue | continue | 跳过本次循环，继续下一次 |
|  else 子句 | else clause | 循环正常结束后执行的代码 |

## 四、函数相关

| 术语 | 英文 | 解释 |
|------|------|------|
| 函数 | Function | 可复用的代码块，用 `def` 定义 |
| 参数 | Parameter | 函数定义时的输入变量 |
| 参数 | Argument | 函数调用时传入的实际值 |
| 返回值 | Return value | 函数用 `return` 返回的结果 |
| 作用域 | Scope | 变量的可见范围（局部、全局） |
| 递归 | Recursion | 函数调用自身 |
| 匿名函数 | Lambda | 一行写的简单函数，如 `lambda x: x*2` |
| 高阶函数 | Higher-order function | 接收函数作为参数或返回函数的函数 |

## 五、面向对象

| 术语 | 英文 | 解释 |
|------|------|------|
| 类 | Class | 创建对象的模板 |
| 对象 | Object | 类的实例 |
| 属性 | Attribute | 类或对象的变量 |
| 方法 | Method | 类中定义的函数 |
| 构造函数 | Constructor | `__init__()`，创建对象时自动调用 |
| 继承 | Inheritance | 子类获取父类的属性和方法 |
| 封装 | Encapsulation | 隐藏内部实现细节 |
| 多态 | Polymorphism | 同一个方法在不同类中有不同实现 |

## 六、模块与包

| 术语 | 英文 | 解释 |
|------|------|------|
| 模块 | Module | 一个 `.py` 文件，包含函数和变量 |
| 包 | Package | 包含多个模块的文件夹 |
| 导入 | Import | 使用 `import` 引入模块 |
| 标准库 | Standard Library | Python自带的模块集合 |

## 七、异常处理

| 术语 | 英文 | 解释 |
|------|------|------|
| 异常 | Exception | 程序运行时的错误 |
| try-except | try-except | 捕获异常的语句 |
|  else 子句 | else clause | 没有异常时执行的代码 |
| finally | finally | 无论是否异常都执行的代码 |
| 抛出异常 | Raise exception | 用 `raise` 主动触发异常 |

## 八、常用内置函数

| 函数 | 说明 |
|------|------|
| `print()` | 输出到控制台 |
| `input()` | 从控制台读取输入 |
| `len()` | 返回长度 |
| `type()` | 返回数据类型 |
| `int()` | 转换为整数 |
| `str()` | 转换为字符串 |
| `float()` | 转换为浮点数 |
| `list()` | 转换为列表 |
| `range()` | 生成整数序列 |
| `sum()` | 求和 |
| `max()` / `min()` | 最大值/最小值 |
| `sorted()` | 排序 |

## 九、列表常用方法

| 方法 | 说明 |
|------|------|
| `append(x)` | 末尾添加元素 |
| `insert(i, x)` | 在位置 i 插入元素 |
| `remove(x)` | 删除第一个值为 x 的元素 |
| `pop(i)` | 删除并返回位置 i 的元素 |
| `sort()` | 排序 |
| `reverse()` | 反转 |

## 十、字符串常用方法

| 方法 | 说明 |
|------|------|
| `lower()` | 转小写 |
| `upper()` | 转大写 |
| `strip()` | 去除两端空格 |
| `split()` | 分割成列表 |
| `join()` | 用分隔符合并列表 |
| `find()` | 查找子串位置 |
| `replace()` | 替换子串 |

## 十一、字典常用方法

| 方法 | 说明 |
|------|------|
| `keys()` | 获取所有键 |
| `values()` | 获取所有值 |
| `items()` | 获取所有键值对 |
| `get(k)` | 安全获取值，不存在返回 None |
| `pop(k)` | 删除并返回键 k 的值 |

## 十二、文件操作

| 术语/函数 | 说明 |
|----------|------|
| 文件对象 | File object，用 `open()` 打开 |
| `open()` | 打开文件，模式：`'r'`、`'w'`、`'a'` |
| `read()` | 读取全部内容 |
| `readline()` | 读取一行 |
| `write()` | 写入内容 |
| `close()` | 关闭文件 |
| with 语句 | 自动关闭文件，如 `with open(...) as f:` |

| 库名 | 说明 |

| `os` | 操作系统接口 |
| `sys` | 系统相关参数 |
| `re` | 正则表达式 |
| `json` | JSON 数据处理 |
| `itertools` | 迭代器工具 |
| `functools` | 高阶函数工具 |
| `collections` | 额外数据结构 |

## 十四、编程概念

| 术语 | 英文 | 解释 |
|------|------|------|
| 算法 | Algorithm | 解决问题的方法和步骤 |
| 数据结构 | Data Structure | 组织数据的方式 |
| 时间复杂度 | Time Complexity | 算法运行时间与数据规模的关系 |
| 空间复杂度 | Space Complexity | 算法占用内存与数据规模的关系 |
| 递归深度 | Recursion Depth | 递归调用的层数 |
| 栈溢出 | Stack Overflow | 递归过深导致内存耗尽 |
| 可变 | Mutable | 对象内容可改变（如 list） |
| 不可变 | Immutable | 对象内容不可改变（如 tuple、str） |
| 可迭代对象 | Iterable | 可用 `for` 遍历的对象 |
| 迭代器 | Iterator | 实现 `__next__()` 的对象 |
| 生成器 | Generator | 用 `yield` 创建的特殊迭代器 |
