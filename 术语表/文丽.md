# 📚 术语表

| 术语 | 英文 | 释义 |
|------|------|------|
| 归约 | Reduce / Fold | 对一组数据反复施加同一个二元操作，最终得到单一结果的抽象模式；`sum`、`max`、`product`都是归约的特例 |
| 尾递归 | Tail Recursion | 递归调用是函数最后一步操作，中间结果通过累积器参数传递；Python不做尾调用优化（TCO），实际上不能节省调用栈 |
| 分治 | Divide and Conquer | 将问题拆分为若干子问题分别求解再合并结果；求和的分治版本递归深度为O(log n)，但串行实现反而比循环慢 |
| 惰性求值 | Lazy Evaluation | 只在需要时才生成下一个元素，不提前构建完整数据结构；生成器表达式是Python中惰性求值的典型实现，额外内存O(1) |
| 浮点误差 | Floating Point Error | 浮点数在二进制表示中存在精度限制，多次累加会积累舍入误差；对精度敏感场景需使用`math.fsum`或Kahan算法 |
| Kahan补偿求和 | Kahan Summation | 通过维护误差补偿量`c`来修正每步舍入偏差的算法，显著降低浮点累积误差，比普通sum慢约4倍 |
| 面板数据 | Panel Data | 同时包含截面维度（多个个体）和时间维度的数据集；本次作业为4国×10年=40行的均衡面板 |
| 相关系数 | Correlation Coefficient (r) | 衡量两个变量线性相关程度的统计量，取值范围[-1,1]；\|r\|<0.3为弱相关，0.3~0.5为中等，>0.5为强相关 |
| 追赶效应 | Convergence Effect | 经济学中人均收入较低的国家往往增速更快、逐渐向富裕国家靠拢的现象；本次数据中r(GDP增长,人均GDP)=-0.528即体现此规律 |
| 遗漏变量 | Omitted Variable | 回归模型中未纳入但实际影响因变量的变量；本次OLS曲面残差较大，说明仅用FDI和人均GDP无法充分解释增长差异 |
| 国别异质性 | Country Heterogeneity | 不同国家在不可观测特征（制度、文化、历史）上的系统性差异；忽略异质性直接池化回归会导致估计偏差 |
| 固定效应模型 | Fixed Effects Model | 面板回归中控制个体不可观测固定特征的方法，通过个体内部的时间变化识别参数；是处理国别异质性的标准方法 |
| OLS | Ordinary Least Squares（普通最小二乘法） | 通过最小化残差平方和估计回归系数的方法；本次用`np.linalg.lstsq`手动实现，拟合GDP增长率关于FDI和人均GDP的线性曲面 |
| DRY原则 | Don't Repeat Yourself | 软件开发原则，核心是"发现抽象、消除重复"；在本次作业中的体现是：13种写法不是13份重复代码，而是同一个reduce抽象的13个投影 |
