# 易错题1：交错序列求和（符号与分母规律）第二章7-5

## 📌 题目描述
计算交错序列 1 - 2/3 + 3/5 - 4/7 + 5/9 - 6/11 + ... 的前N项之和。

## ❌ 常见错误

### 错误1：符号规律搞反
```python
# 错误写法
if i % 2 == 0:  # 认为偶数项是正号
    total += i / (2 * i - 1)
else:
    total -= i / (2 * i - 1)
```
### 错误2：分母公式算错
错误写法 →　denominator = 2 * i + 1  # 应该是 2*i - 1

### 错误写法 忘记保留三位小数
错误写法 → print(total)  # 没有格式化

### 正确做法
```python
n = int(input())
total = 0.0

for i in range(1, n + 1):
    if i % 2 == 1:  # 奇数项为正
        total += i / (2 * i - 1)
    else:            # 偶数项为负
        total -= i / (2 * i - 1)
 
print(f"{total:.3f}")
```
| 易错点 | 正确规律 |
|--------|---------|
| 符号 | 奇数项正(+)，偶数项负(-) |
| 分母 | 第i项分母 = 2×i - 1 |
| 分子 | 第i项分子 = i |
| 输出格式 | `f"{total:.3f}"` 保留三位小数 |

# 易错题2：从右向左输出字符索引

## 📌 题目描述
输入一个字符串和两个字符，从右向左输出这两个字符在字符串中的位置索引（下标最大的最先输出）。

## ❌ 常见错误

### 错误1：从左向右遍历
```python
# 错误写法
for i in range(len(s)):
    if s[i] == c1 or s[i] == c2:
        print(i, s[i])  # 输出顺序是左→右，不是右→左
```
### 错误2：符号规律搞反
```python
# 错误写法
for i in range(len(s), 0, -1):  # 会漏掉索引0
    print(i, s[i])  # 还会出现索引越界
```
### 错误3：条件判断用and而不是or
```python
# 错误写法
if s[i] == c1 and s[i] == c2:  # 永远为False
```

## ✅ 正确做法
```python
s = input()
c1, c2 = input().split()

for i in range(len(s) - 1, -1, -1):
    if s[i] == c1 or s[i] == c2:
        print(i, s[i])
```
## 💡 易错点总结

| 易错点 | 正确写法 |
|--------|---------|
| 遍历方向 | `range(len(s)-1, -1, -1)` 从右向左 |
| 条件判断 | 用 `or`，不是 `and` |
| 索引范围 | 从 `len(s)-1` 到 `0`（包括0） |

# 易错题3：删除字符（大小写不敏感）

## 📌 题目描述
输入一个字符串和要删除的字符（非空格），大小写不区分，删除字符串中所有出现的该字符。

## ❌ 常见错误

### 错误1：没有处理大小写
```python
# 错误写法
if ch != c:  # 'B' != 'b' 会出错
    result += ch
```
### 错误2：忘记去掉两端空格
```python
# 错误写法
s = input()  # 没有 .strip()
c = input()
```
### 错误3：试图用replace但写错
```python
# 错误写法
s.replace(c, '')  # replace不会自动处理大小写
```
### 错误4：循环中修改正在遍历的字符串
```python
# 错误写法
for ch in s:
    s = s.replace(ch, '')  # 危险！边遍历边修改
```
## ✅ 正确做法
```python
s = input().strip()
c = input().strip()
c_lower = c.lower()

result = ""
for ch in s:
    if ch.lower() != c_lower:
        result += ch

print(result)
```
## 💡 易错点总结

| 易错点 | 正确做法 |
|--------|---------|
| 大小写不敏感 | 都用 `.lower()` 转换后再比较 |
| 两端空格 | `.strip()` 去除空格 |
| 字符串拼接 | 用新变量 `result` 收集结果 |
| 原地修改 | 不要边遍历边修改原字符串 |

## 易错题总结表

| 题目 | 核心易错点 | 关键代码 |
|------|-----------|---------|
| 交错序列求和 | 符号规律、分母公式、输出格式 | `if i % 2 == 1`、`2*i-1`、`f"{total:.3f}"` |
| 字符索引输出 | 反向遍历、条件判断 | `range(len(s)-1, -1, -1)`、`or` |
| 删除字符 | 大小写处理、去除空格 | `.lower()`、`.strip()`、新字符串拼接 |
