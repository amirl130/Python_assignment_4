## 一、作业一：大学生活模拟器

### 1. 边界条件

递归函数忘记处理空列表：

```python
# 错误
def sum_recursive(data):
    return data[0] + sum_recursive(data[1:])

# 正确
def sum_recursive(data):
    if not data:
        return 0
    return data[0] + sum_recursive(data[1:])
```
### 2. 属性值变负数

```python
# 错误
phy_health -= 5

# 正确
phy_health = max(0, phy_health - 5)
```

### 3. while 死循环

```python
# 错误
i = 0
while i < len(data):
    total += data[i]

# 正确
i = 0
while i < len(data):
    total += data[i]
    i += 1
```

## 二、作业二：求和知识库

### 4. 空列表 + reduce

```python
# 错误
from functools import reduce
sum_reduce = lambda x: reduce(lambda a,b: a+b, x)

# 正确
def sum_reduce(data):
    if not data:
        return 0
    return reduce(lambda a,b: a+b, data)
```

### 5. 生成器只能消费一次

```python
# 错误
gen = (x for x in data)
total1 = sum(gen)
total2 = sum(gen)  # 第二次为 0

# 正确：只使用一次
total = sum(x for x in data)
```

### 6. 递归深度超限

```python
# 错误
def sum_recursive(data):
    return data[0] + sum_recursive(data[1:])

# 正确：改用迭代
def sum_for(data):
    total = 0
    for x in data:
        total += x
    return total
```

### 7. 浮点数精度

```python
# 错误
sum([0.1] * 10)  # 0.9999999999999999

# 正确
import math
math.fsum([0.1] * 10)  # 1.0
```

### 8. 列表推导式内存

```python
# 错误：内存翻倍
sum([x for x in data])

# 正确：生成器不占额外内存
sum(x for x in data)
```

### 11. lstsq 返回值解包

```python
# 错误

# 正确
beta = np.linalg.lstsq(X, Y, rcond=None)[0]
```
