## 一、作业一：大学生活模拟器

### 1. 边界条件

递归函数忘记处理空列表：

```python
# 错误
def sum_recursive(data):
    return data[0] + sum_recursive(data[1:])

# 正确
def sum_recursive(data):
    if not data:
        return 0
    return data[0] + sum_recursive(data[1:])
```
### 2. 属性值变负数

```python
# 错误
phy_health -= 5

# 正确
phy_health = max(0, phy_health - 5)
```

### 3. while 死循环

```python
# 错误
i = 0
while i < len(data):
    total += data[i]

# 正确
i = 0
while i < len(data):
    total += data[i]
    i += 1
```
